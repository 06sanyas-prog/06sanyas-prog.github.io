## Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/06sanyas-prog/06sanyas-prog.github.io.git

# Navigate into the project folder
cd 06sanyas-prog.github.io

# Open index.html in your browser
```

No build tools or dependencies required — just open `index.html` directly, or use a live server extension for auto-reload during development.
